# Third-party licence and dependency checklist

Before adopting any code, package, model, dataset or hosted service, record:

- Project name, canonical repository and exact commit/tag.
- Licence file and SPDX identifier at that exact version.
- Copyright/NOTICE/attribution obligations.
- Copyleft, network-copyleft, source-disclosure or linking obligations.
- Commercial use and SaaS use permissions.
- Trademark, logo, font, image, model and dataset restrictions.
- Security advisories, last release, maintainer activity and dependency health.
- Build/runtime requirements and whether it can run within the current architecture.
- Data sent to the service, subprocessors, retention and privacy implications.
- Hosting, bandwidth, storage, CPU, API quota and ongoing cost.
- Exit plan if the project becomes unavailable or changes licence.

A GitHub public repository is not automatically licensed for reuse. If no licence is present or the licence is unclear, treat the code as unavailable for copying; use only independently developed ideas that do not reproduce protected expression.
